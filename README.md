# 六边形地图标注 · 玄机规划工作台

一个纯前端、零依赖、单 HTML 文件的六边形地图规划工具：为策略类游戏标注地图、计算"玄机采集"总分，并自动求出特殊格的最优摆放。

## 快速开始

无需安装任何东西。下载 `hex-planner.html`，双击用浏览器打开即可使用。

也可放到任意静态服务器（GitHub Pages / 内网共享目录等）直接访问。

## 功能

### 地图标注
- 六边形轴向坐标 (q, r) 地图，半径 1~14 可调，支持缩放/平移/旋转 60°
- 四种特殊格 + 普通资源格，左键点击或拖动批量绘制
- 任意颜色涂装 + 图例含义备注
- 撤销/重做（Ctrl+Z / Ctrl+Y），快捷键切换工具（1~4 操作工具，Q/W/E/R/T 格子类型，F 居中适配）

### 得分计算（实时）
| 类型 | 标签 | 作用 | 被采集 |
|------|------|------|--------|
| 普通资源格 | （无） | 有基础资源值 | 是 |
| 玄机格 ✦ | `玄` | 采集半径 R（默认 3）内所有非玄机格 | 否 |
| 苦功格 ⚒ | `苦` | 相邻 6 格每格 +2 | 是 |
| 嫁衣格 ◕ | `嫁` | 相邻 6 格每格 +1 | 是 |
| 循序格 ↻ | `循`/`序` | 实际分 += 相邻在图格子数（内圈恒 6） | 是 |

总分 = Σ (被采集格实际分 × 被几个玄机覆盖)，实时显示总分、每个玄机格采集量、每格贡献明细。

### 自动求解
输入这局拿到的特殊格数量，求解器自动摆到最优位置：

- **精确求解**：枚举玄机拓扑 + MCMF（最小费用最大流）精确分配，数学最优。已验证优于退火基线（677 分 vs 665 分）
- **退火求解**：模拟退火，快但不保证最优，可换种子多次取优
- 结果自动对称化：在 6 种旋转等价解中选最对称、最居中的摆法

### 数据交换
- **HexMap 文本**：与 AI 交流用的紧凑文本格式，可导出/导入/贴给 AI 复核
- **JSON 备份**：完整数据备份
- **链接分享**：地图状态自动存入 URL，刷新不丢；一键复制链接发给他人，打开即是同一张图

## 使用流程

1. 标好地图（或留空），设置地图半径、玄机覆盖半径、背景资源
2. 实时查看「规划」页的总分与采集明细
3. 需要自动摆放时：填特殊格数量 → 点「求最优摆布」（会先清空地图上的特殊格再重摆）
4. 「数据」页导出 HexMap 文本贴给 AI 复核，或复制链接分享
